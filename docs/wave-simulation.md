# Wave自動シミュレーション

主要Waveの敵編成・HP・盾・出現間隔・経路移動と、固定した基準タワー配置による撃破結果をNode.js上で再現します。

```bash
npm test
npm run simulate:waves
```

対象はストーリー各章の最終Wave（3・6・10・14・18・24）と、エンドレスの主要な導入・分岐・ボスWaveです。乱数シードは固定されているため、同じコードと設定からは同じ結果になります。

テストでは次を確認します。

- すべての敵種が `game-data.js` に存在する
- HP・盾・速度が有限の正数になる
- 本線とWave 35以降の分岐経路で敵が停止しない
- 代表Waveが上限フレーム内に終了する
- ボスWaveに必要な固有敵が含まれる
- 基準タワー配置の撃破数・取り逃し数が意図せず変わらない

このシミュレーションはブラウザ描画、効果音、演出、ショップ操作を実行しません。基準配置は攻略例や勝利保証ではなく、Wave設定変更による大きな退行を検出するための固定負荷です。最終的な難易度判断は実機プレイと併用します。
