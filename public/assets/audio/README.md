# Audio assets

Place the final audio files in this directory using these exact names:

## BGM (looped, default volume 60%)

- `title.mp3`
- `stage.mp3`
- `boss.mp3`
- `library.mp3`
- `ending.mp3`
- `gameover.mp3`

## Sound effects (default volume 70%)

- `place.mp3`
- `snack.mp3`
- `hit.mp3`
- `unlock.mp3`
- `error.mp3`
- `page.mp3`
- `hover.mp3`
- `trap.mp3`
- `boss_intro.mp3`
- `clear.mp3`
- `life_lost.mp3`
- `select.mp3`
- `gameover_se.mp3`

Missing files are reported once in the browser console and do not stop the game.
